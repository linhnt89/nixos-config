# Global Agent Guidelines

- Inspect project instructions, repository state, and existing patterns before changing anything.
- Keep changes focused and preserve unrelated or uncommitted work.
- Prefer repository-provided environments, tools, and commands over modifying the host or installing global dependencies.
- Avoid destructive Git operations, history rewriting, or remote changes unless explicitly requested.
- Never expose or commit credentials, tokens, private keys, or other secrets.
- Follow existing project conventions unless there is a clear reason to change them.
- Run relevant repository-provided checks and report what was validated and what could not be tested.
- For unfamiliar or fast-changing technical facts, verify authoritative documentation when possible rather than guessing.
